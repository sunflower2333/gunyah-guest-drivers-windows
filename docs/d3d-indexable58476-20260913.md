# D3D shader array correction candidate 58476

The installed 58474 package creates an ARM64 D3D11 FL10_1 device but the normal
system-runtime draw test leaves all pixels at the clear color. Actual shader
tracing attributes this to DXBC indexable temporary arrays being declared as
scalar TGSI temporaries: the NIR translator loses the dynamic array index and
all triangle vertices collapse to one point.

This candidate pins Mesa 91316f199e9c066109c7832e72653e65754349fa, whose D3D
frontend emits actual TGSI temporary arrays. The KMD and D3D UMD are rebuilt
and signed in the normal joint flat package. GL/Vulkan use the matching Mesa
source through producer 34727218408. Installed OpenCL source 0f436fe remains
the baseline; experimental duration/tiled submission policies are separate.

Version 100.6.101.58476 is reserved for this candidate (58475 belongs to the
separate CL duration candidate). All 35 local flat package tests pass. Full
signed CI and actual target validation are still required.

Repeat the unchanged ordinary system-runtime shader probe from
gunyah-guest-drivers-windows 1d4e5e4bf60aaf59008ab6be9729ec6bc2dbbd30 after
installation. Required result is 16,384 exact pixels and four successful
Presents, with the actual loaded UMD path/hash verified. This does not by
itself prove visible final host pixels, 165 Hz, higher D3D feature levels,
x86/x64 D3D, native D3D12, full GB7 or the Full Display+Render goal.
